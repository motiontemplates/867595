## 技术原理

- 声明的运行配置：html-canvas/1。
- 通过模板参数和预设，将本期文字、数据或素材映射到已有动画工程。
- 已声明时间轴为固定时长，本期内容按现有场景顺序和节奏适配。

样片时长: **57s**. 已声明输出为 1920 × 1080，60 fps；公开样片 57 秒。 按实际包的参数边界制作；增加素材不会自动增加场景。

## 输入素材与内容

- **可选:** 本期产品图片、截图或展示素材，按所选槽位支持的类型准备。
- **必需:** 本期品牌名称、Logo，以及实际需要的功能图标。
- **必需:** 本期主题、文稿与需要准确保留的信息。
- **可选:** 本期已授权配乐，或本期是否需要配乐的偏好。
- **可选:** 本期配音文件，或是否需要配音的安排。

适用内容: Digital tools, reusable creative formats, feature explanations · Keyword, comparison, process, repeated output, network and conclusion scenes
